Importance Sampling

Estimating expectations by averaging random draws, and what to do when you can't draw from the distribution you care about. Read the pins, then play with the three labs: every number on this page comes from a live simulation in your browser.

sample where it's easy → reweight to where it counts

Where this fits in the quarter

Part 1

Classical Monte Carlo integration

Any integral you can write as an average can be estimated by sampling. That one reframing is the engine of the whole chapter.

An integral is an average in disguise

The average height of h over (a, b) is the integral divided by the width. Multiply the density of Unif(a, b) into the integrand and the integral becomes an expectation:

∫ab h(x) dx = (b − a) · E[h(X)],  X ~ Unif(a, b)

So: estimate the expectation, then rescale by the width.

The big reframe•••

The simple Monte Carlo recipe

  1. Draw X(1), …, X(n) independently from Unif(a, b).
  2. Evaluate h at every draw.
  3. Average them: h̄n = 1n Σ h(X(i)), then report În = (b − a) h̄n.
Three steps, every time•••

Why it works

  • Unbiased. Each term has mean E[h(X)], so the average does too.
  • Variance shrinks like 1/n. Var(h̄n) = Var[h(X)] / n, and the width factor enters squared for În.
  • Strong LLN: h̄n converges to the truth almost surely.
  • CLT: the standardized error is approximately N(0, 1), which gives you error bars.
Guarantees•••

Error bars from the same draws

Estimate the variance of the average with the spread of your own samples:

vn = 1n² Σ (h(X(i)) − h̄n)²

Then h̄n ± 1.96√vn is an approximate 95% band. Watch it pinch inward in Lab 1.

Monte Carlo error•••

Probabilities are expectations too

For Z ~ N(0,1), the CDF has no closed form. But the indicator I(Z ≤ x) is a Bernoulli variable with success probability F(x), so

F(x) = E[ I(Z ≤ x) ]

The estimate is just the fraction of draws that land at or below x. Its variance is F(x)(1 − F(x))/n, which peaks at F = ½, so 1/(4n) is a safe worst case.

Example 2 · Normal CDF•••

Where uniform sampling struggles

  • If h is spiky, most uniform draws land where nothing happens, so the estimate is noisy.
  • There is no uniform distribution on (0, ∞) or (−∞, ∞).

The fix: think in expectations under a general density f. If you can sample from f, the same recipe works with X ~ f.

Part 2

Importance sampling

You want Ef[h(X)] but can't draw from f. Borrow the rejection-sampling idea: find a stand-in you can draw from, then correct for the mismatch.

Pick a trial distribution g

  • Covers f. g(x) > 0 everywhere f(x) > 0. Otherwise whole regions are never visited.
  • Easy to sample. Inverse CDF, a built-in generator, anything that works.
Two checks before you start•••

The one-line trick

Multiply and divide by g, then read the integral as an expectation under g:

Ef[h(X)] = ∫ h(x) f(x)g(x) g(x) dx = Eg[ h(X) f(X)g(X) ]

Outside the support of f the integrand is zero, so extending the integral over all of g's support changes nothing.

Change of measure•••

Definition

w(x) = f(x) / g(x)

The importance weight says how much more (or less) likely a point is under f than under the distribution that actually produced it.

if g = f, every weight is 1 and you're back to plain Monte Carlo

Importance weight•••

The importance sampling estimator

  1. Draw X(1), …, X(n) ~ g and compute each weight w(X(i)).
  2. Average the weighted values: Êf[h(X)] = 1n Σ w(X(i)) h(X(i)).
Algorithm•••

Sanity check: weights average to 1

Eg[w(X)] = ∫ f(x)g(x) g(x) dx = ∫ f(x) dx = 1

So the sample mean of your weights should sit close to 1. If it doesn't, suspect a bug in f, g, or the weight formula.

Debugging habit•••

Efficiency

The further g strays from f, the more the weights swing, and a few huge weights can dominate the average. A simple score:

Efficiency = 1 / Varg[w(X)]

Lab 3 plots this against the rate of the exponential proposal so you can see the sweet spot.

Choosing g well•••

Example 3 setup

Target: the folded (half) normal, f(x) = √(2/π) e−x²/2 for x ≥ 0, with h(x) = x.

Proposal: Exp(λ = 2), g(x) = 2e−2x. Same support, and the inverse CDF gives draws.

Weight: w(x) = 1√(2π) exp(−x²/2 + 2x).

Answer to check against: Ef(X) = √(2/π) ≈ 0.79788, via the substitution u = x²/2.

Cheat sheet

Importance sampling in R

# Folded normal mean via an Exp(2) proposal
set.seed(102)
n <- 1e4
x <- rexp(n, rate = 2)              # draws from g
f_x <- 2 * dnorm(x)                  # target density
g_x <- dexp(x, rate = 2)             # proposal density
w <- f_x / g_x                         # importance weights

est <- mean(w * x)
se <- sd(w * x) / sqrt(n)
c(estimate = est, se = se, mean_w = mean(w))

Using dnorm and dexp keeps the weight formula honest; it matches the hand-simplified exp(−x²/2 + 2x)/√(2π).
